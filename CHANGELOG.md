## [0.1.0] - 2026-10-17

### Added

- Rspress static site with the default theme, with top navigation for CLI, Patterns and Concepts.
- Mermaid diagram support through `rspress-plugin-mermaid`.
- CLI cheatsheets: `git rebase`, `age`, `sops` and Vim navigation.
- GitHub Actions workflow publishing the site to GitHub Pages on push to `main`.
- Claude Code skills `new-cheatsheet` (with CLI, pattern and concept templates) and `build-cheatsheets`.
- README describing the project, conventions and deployment.
